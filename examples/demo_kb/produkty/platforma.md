# Платформа Operon Core

ВЫМЫШЛЕННЫЕ ДАННЫЕ ДЛЯ ДЕМОНСТРАЦИИ.

## Что это
Платформа управления операционными процессами для среднего бизнеса.
Подписочная модель, развёртывание в облаке.

## Состав
- Модуль учёта заявок
- Модуль отчётности
- Интеграционный шлюз (REST)

## Ограничения
Не поддерживает развёртывание на собственных серверах клиента.
Максимум 500 одновременных пользователей на одном экземпляре.

## Ценообразование
Подписка за пользователя в месяц. Действующие ставки — в разделе тарифов,
файл `tarify/tarify-2026.csv`.
