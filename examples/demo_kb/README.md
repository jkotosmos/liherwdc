# Демонстрационная база знаний

Все данные в этом каталоге **вымышлены** и существуют только чтобы проверить
работоспособность поиска и посмотреть, как ассистент ссылается на источники.
Ни одна цифра здесь не относится к реальной компании.

Запуск ассистента на демо-данных:

```bash
OPERON_KB_DIR=examples/demo_kb python run.py
```

Для работы с реальными данными держите документы в `knowledge_base/` —
этот каталог трогать не нужно.
